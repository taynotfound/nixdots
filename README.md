# NixDots

A reproducible NixOS desktop built around Hyprland. It keeps Hyprland's speed and keyboard control, but behaves like a desktop environment: windows float and center by default, can be dragged and resized with the mouse, and have titlebar buttons for close, maximize, minimize, and hide.

## Included

- NixOS + flakes + Home Manager
- Hyprland with desktop-style floating windows
- `hyprbars` titlebars with Font Awesome 6 icons
- Close, maximize, minimize, hide, and restore actions
- Waybar top panel and an autohiding application dock
- Rofi Wayland launcher, Dolphin, Kitty, and Firefox
- SwayNC notifications, NetworkManager, Bluetooth, PipeWire
- Hyprlock, Hypridle, screenshots, and clipboard history
- Papirus Dark icons, Bibata cursor, and adw-gtk3 dark GTK theme
- Optional NVIDIA detection during installation
- Automatic Nix garbage collection and optimisation

## Requirements

- An already-installed NixOS system
- A normal user with `sudo` access
- `/etc/nixos/hardware-configuration.nix` generated by the NixOS installer
- Network access for the first flake evaluation

This repository is a configuration template. Do not copy the committed machine files from another computer: `install.sh` generates them locally.

## Install

Clone the repository and run the installer:

```bash
nix --extra-experimental-features 'nix-command flakes' shell nixpkgs#git -c \
  git clone https://github.com/taynotfound/nixdots.git ~/.config/nixdots
cd ~/.config/nixdots
./install.sh
```

The installer:

1. Verifies that the system is NixOS and that hardware configuration exists.
2. Detects your username, hostname, timezone, and NVIDIA hardware.
3. Detects the GRUB target (`nodev` for UEFI, the root disk for BIOS) and writes local machine data under `hosts/`.
4. Temporarily marks the generated host files Git-visible so flakes can evaluate them, without committing them.
5. Creates or refreshes `flake.lock`.
6. Runs `nixos-rebuild switch` with the Hyprland binary cache.

If `git` is not installed yet, the installer temporarily provides it through `nix shell` and continues automatically.

Then log out and select **Hyprland** in SDDM, or reboot.

### Optional installer settings

```bash
NIXDOTS_USER=alice \
NIXDOTS_HOSTNAME=workstation \
NIXDOTS_TIMEZONE=Europe/Berlin \
./install.sh
```

## Controls

| Action | Shortcut |
|---|---|
| Applications | `SUPER+D` or `SUPER+R` |
| Terminal | `SUPER+Q` |
| File manager | `SUPER+E` |
| Close | `ALT+F4` or `SUPER+C` |
| Maximize | `SUPER+F` or double-click the titlebar |
| Minimize | `SUPER+M` |
| Restore minimized | `SUPER+SHIFT+M` |
| Hide | `SUPER+H` |
| Restore hidden | `SUPER+SHIFT+H` |
| Float / tile | `SUPER+T` |
| Move focus | `SUPER` + arrow keys |
| Move window | `SUPER`/`ALT` + left mouse button |
| Resize window | `SUPER`/`ALT` + right mouse button |
| Lock screen | `SUPER+L` |
| Power menu | `SUPER+SHIFT+E` |
| Region screenshot | `Print` |

Minimized and hidden windows appear in Waybar when available. Clicking the icon opens a small Rofi restore picker.

## Update

```bash
cd ~/.config/nixdots
./update.sh
```

To validate without changing the running system:

```bash
./check.sh
```

`check.sh` runs `nix flake check --no-build`, rejects the removed legacy Lua Hyprland config, and runs `nixos-rebuild dry-build`. `update.sh` updates all flake inputs, checks the flake, and rebuilds the system. Use it deliberately: updating inputs can change Hyprland and system packages.

To rebuild without updating inputs:

```bash
sudo nixos-rebuild switch --flake ~/.config/nixdots#nixdots
```

## Remove

To remove the system configuration while keeping the repository:

```bash
cd ~/.config/nixdots
./remove.sh
```

The script switches to the previous NixOS generation and removes this checkout after confirmation. It does not delete personal files from your home directory.

To remove only the checkout:

```bash
rm -rf ~/.config/nixdots
```

## Layout

```text
flake.nix                         NixOS entry point
nixos/configuration.nix            System configuration
home/home.nix                     Home Manager + Hyprland config
waybar/                            Panel configuration and styling
nwg-dock-hyprland/                 Dock styling
hypr/                              Lock and idle configuration
scripts/nixdots-windowctl          Window lifecycle helper
hosts/*-example.nix                Templates; generated files are local only
install.sh                         First install/bootstrap
update.sh                          Flake update + rebuild
remove.sh                          Roll back and remove checkout
```

## Troubleshooting

### The Hyprland session is missing

Run `./install.sh` again and check that SDDM is enabled. You can inspect available sessions with:

```bash
ls /usr/share/wayland-sessions/
```

### A configuration change does not appear

Rebuild and reload Hyprland:

```bash
sudo nixos-rebuild switch --flake ~/.config/nixdots#nixdots
hyprctl reload
```

### A plugin fails to load

Hyprland plugins are ABI-sensitive. Keep the `hyprland` and `hyprland-plugins` inputs on compatible releases, then run `./update.sh` to refresh the lock file.

### Roll back a failed rebuild

```bash
sudo nixos-rebuild switch --rollback
```
